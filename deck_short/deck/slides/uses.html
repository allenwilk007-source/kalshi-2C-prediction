Play the future: watch a bet win or lose, one simulated year at a time

Beyond a single bet, here’s where the model could go. Checking other markets: the same code already prices Kalshi’s other climate contracts, whether 2026 will be the hottest year, monthly temperature records, and CO₂ levels at Mauna Loa. A transparent model gives you a reference point for any of them. Hedging climate risk: businesses exposed to warming, like insurers, utilities and farms, could use contracts like this as a hedge, and a model like this to judge whether the price is fair. I also computed the social cost of carbon from the same model. Teaching and explaining: it shows how each input we used in class, from emissions growth to climate sensitivity, changes a real-world probability, and why the width of the uncertainty matters as much as the central estimate. Tracking it live: the full dashboard refreshes the data and prices with one button. Adding seasonal El Niño forecasts, methane and aerosols would make it a live forecasting tool. You can try all of it yourself. The Tool Dashboard is one file in the GitHub repo: download it, double-click, and it runs in your browser. Thank you.
