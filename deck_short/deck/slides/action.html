Finally, what could someone do with these numbers? This is a classroom exercise: we placed no trades, and none of it is investment advice. The rule is simple. Buying Yes costs 73.4 cents including the fee, so it’s only worth it if you believe the chance is above 73.4%. Buying No costs 34.5 cents, so it’s only worth it if you believe the chance is below 65.5%. In between, the price is fair to you and you pass. Now put our numbers on that line. If you trust our 72-version model’s 81%, you’d buy Yes. $100 buys 136 contracts: you win $36 if a 2°C year happens, lose $100 if it doesn’t, and on average expect about $10. If you trust the IPCC-calibrated 67%, it falls in the pass zone, so there’s no trade. And this is where it becomes personal: if you believe something will happen, you can see its effect. For example, if you believe emissions fall to net zero by 2070, the model’s chance drops to 44%, so you’d buy No: 289 No contracts, plus $189 if no year reaches 2°C, minus $100 if one does, expected about $63. The dashboard lets you do this for any combination of beliefs.
